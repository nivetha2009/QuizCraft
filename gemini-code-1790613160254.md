# QuizCraft

QuizCraft is an interactive student website that allows users to generate, practice, and review multiple-choice quizzes across any subject and topic.

## Features
- **Custom Quiz Creation:** Choose any subject, topic, difficulty level (Easy, Medium, Hard), and question count (5 to 20).
- **Built-in Subject Bank:** Pre-loaded questions for Economics, Financial Accounting, Mathematics, and Computer Science.
- **Dynamic Question Engine:** Automatically generates topic-specific fallback questions for custom input.
- **Distraction-Free Quiz Experience:** One-question-at-a-time view with interactive progress indicator.
- **Detailed Results Analysis:** Score display, percentage, correct answer review, and explanations for every question.
- **Instant Retake & New Quiz Flow:** Try quizzes again or easily reset configuration.

## Tech Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
